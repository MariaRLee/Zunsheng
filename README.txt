這是可直接部署 GitHub Pages 的純靜態網站。檔案皆在同一層，無需移動 volumes 資料夾。

UPLOAD / 上傳方法
1. 將本 ZIP 解壓縮。不要直接把 ZIP 檔上傳作為網站。
2. 前往新 GitHub repository 的首頁。
3. Add file → Upload files → Choose your files，選取解壓縮後全部 10 個網站檔案（README 可選）。
4. Commit changes。
5. Settings → Pages → Deploy from a branch → main / (root)。
6. 開啟 https://<username>.github.io/<repository>/。
