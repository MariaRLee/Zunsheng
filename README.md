## 如何使用
1. 解壓縮整個資料夾，直接雙擊 `index.html` 開啟。
2. GitHub Pages：將本資料夾內所有檔案（`index.html`, `app.js`, `data.js`, `style.css`, `articles`, `volumes`, `assets`）上傳至 GitHub 儲存庫根目錄；在 **Settings → Pages → Deploy from a branch** 選擇 `main` 與 `/ (root)`。
3. 加入新文章時，在 `data.js` 的 `articles` 新增文章資料，並將文章 id 加入對應 `volumes[].articles` 陣列；參照 `articles/qingxiu-opening.html` 建立新頁面，調整 `data-article`。
4. 請務必先校對來源、完成獨立白話翻譯、確認安全/文化註解，再公開新篇章。
